# MyAgent 记忆架构（myagent-memory-architecture）

**版本：v1.0（2026-11-20）** · 作者：[LiMuBai-QiuWuJi](https://github.com/LiMuBai-QiuWuJi)

一套让 AI **记得住、又不把上下文窗口撑爆**的本地记忆架构。核心一句话：**原文永远留在磁盘，每轮只注入「指路行」。**

## 它解决什么

「搞个库全存进去、用的时候检索」听着对，落地全是账——真正贵、真正挤窗口的不是你存了多少，而是**每一轮它得先读多少**。这份包把记忆拆成五个动作，每个动作都有硬上限：

| 动作 | 做法 | 为什么 |
|---|---|---|
| 写 | 一条记忆只写一个事实 | 结论变了就地改写，不用在大杂烩里找该删哪句 |
| 注 | 新会话只注入摘要 + 索引行（行数、字符双上限） | 几百条记忆，进窗口的只有两万多字 |
| 压 | 超预算按优先级挤，挤出去进归档 | 「忘掉」= 从注入面消失，原文不删 |
| 找 | 先精确匹配，0 命中才走一次向量兜底 | 命中只读那一篇，禁止顺链接递归（一次最多 3 个文件） |
| 备 | 每天跑，但只在距上次提交 ≥7 天才真提交 | 周级节流是唯一能长期活下来的频率 |

实测：几百个记忆文件、几十万字符，常驻索引稳定压在 **190 行 / 两万多字符**——**索引长度和记忆总量彻底脱钩**。

## 时间分三层

- **当天流水**：一天一个文件，可以乱、可以重复，**不进长期注入面**，只是缓冲区
- **主题文件**：跨天逐条消费，按内容归主题；同一事实就地改写，旧口径写成「作废 → 现口径」
- **三个触发口子**保证它真的会发生：每天凌晨的计划任务 / 下次会话开始前补提炼 / 一个显式的待处理清单

## 包内文件

```text
myagent-memory-architecture/
├─ README.md              你正在读的
├─ 01-架构说明.md          机制与数据模型（AI 写代码前先读这个）
├─ 02-从零搭建.md          八步逐条命令
├─ 03-日常维护.md          每天/每周/每月各跑什么、脚本的 CLI
├─ 04-验收清单.md          搭完对一遍的打勾清单
├─ install.mjs            一键拷脚本 + 打印下一步
├─ memory-curator/        九个脚本 + 配置模板
└─ 示例库/                最小可跑样本（不含任何真实记忆）
```

## 装起来（压缩包丢给 AI，它自己解压自己搭）

前置：Node.js ≥ 18（实测 22）；一个支持记忆插件的 AI 宿主（实测 DeepSeek Harness，换宿主的话脚本能留、写入那层要自己接）；向量服务 Key 可选，没有就退化成纯关键词匹配；git 与计划任务可选。

1. 下载：本仓库 `Code → Download ZIP`，或网盘那个包。**不用解压**
2. 把压缩包拖进 AI 的对话（拖不进去就贴文件路径）
3. 附上下面这段话

```text
我给你一个 zip 压缩包，路径是 <压缩包路径>。
它是一套完整的 AI 记忆架构（写入 / 注入 / 压缩 / 检索 / 备份五件事）。

请你全自动装好，不要让我手动解压：
1. 解压到一个我能长期放着的位置，告诉我你解到哪了；
2. 阅读顺序：README.md → 01-架构说明.md → 按 02-从零搭建.md 的八步执行；
3. 不要改你自己插件的源码，用包里的脚本和宿主已有的记忆插件对接；
4. 每天 04:00 的计划任务一并建好，否则跨天提炼不会自己发生；
5. 任何一步失败，停下来把报错原文贴给我。

搭完自证三条，缺一条就是没搭对：
1. MEMORY.md 顶部有「摘要区」标记，且总行数 ≤ 200；
2. 用检索脚本搜一句我确实说过的事，能返回真实的记忆文件路径；
3. 记忆目录里有第一次 git 提交。

每一步给我实际输出，不要只说"已完成"。
```

八步本身（解压之后它要做的顺序，供你核对）：拷脚本 → 先聊两句产生几条记忆 → 确认记忆目录生成 → 填向量配置 → 跑预算器（索引变三段式）→ 跑一次检索验证 → 跑每日维护（提炼 + 预算 + 备份）→ 建计划任务。

## 边界

- 摘要与分类的质量上限取决于**调它的模型**，脚本只保证结构，不保证「提炼得好」
- 向量检索只解决「说法不同但意思相关」，不解决「根本没记过」
- 索引 200 行是**注入预算**，不是记忆容量上限
- 不承诺「每轮全量注入」——它能省 token，恰恰是因为平时只注入摘要、命中才读原文
